Sirva **diferentes** tipos de CAPTCHA: `frictionless`, `pow`, `image`.

## CAPTCHA sin fricción

La característica predeterminada `frictionless` de Procaptcha detecta dinámicamente si el usuario está utilizando un navegador normal o navegadores automatizados sin cabeza como [playwright](https://playwright.dev/) o [selenium](https://www.selenium.dev/). Si es probable que el usuario sea un bot, se le presentará un desafío de CAPTCHA de imagen. Si es probable que el usuario sea un *humano*, *no* se le presentará un desafío de CAPTCHA de imagen y en su lugar resolverá un desafío simple e invisible de Proof of Work (PoW).

## CAPTCHA de Proof of Work (PoW)

Un desafío de CAPTCHA de Proof of Work (`pow`) requiere que el usuario resuelva un rompecabezas computacional antes de enviar el formulario. Es fácil de resolver para los humanos, pero computacionalmente costoso para los bots.

<Image src={ProcaptchaGIF} alt={'desafío de captcha pow de prosopo procaptcha'} style="margin: 20px auto;"/>

El tipo de CAPTCHA Proof of Work no interroga el entorno del navegador del usuario, use `frictionless` para eso (arriba).

## CAPTCHA de imagen

Un desafío de CAPTCHA de imagen requiere que el usuario seleccione la(s) imagen(es) correcta(s) que coincidan con la solicitud dada.

El tipo de CAPTCHA de imagen no interroga el entorno del navegador del usuario, use `frictionless` para eso (arriba).
