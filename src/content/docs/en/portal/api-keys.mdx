**API Keys** lists your API keys. Click **Create API Key** to add one.

API access is off by default. Without it, the page shows **API access is not enabled**. Contact support to turn it on.

See [API Keys](/en/advanced/api-keys/) for permissions and usage, and the [API reference](/en/advanced/api/).
