The [Prosopo Portal](https://portal.prosopo.io) is where you manage sites, tune CAPTCHA settings, watch traffic and configure Prosopo Protect.

## Signing in

The portal has no passwords. Enter your email and click **Email me a sign-in link**. The email contains a magic link that signs you in. If it doesn't arrive, click **Click to try again**. New users can click **Sign Up for Free**.

If your session expires, the portal sends you back to the login page with a notice.

## Navigation

The main menu contains:

| Menu entry | What it does |
|---|---|
| [Overview](/en/portal/overview/) | Account summary, live sessions and top IPs |
| [Traffic](/en/portal/traffic/) | CAPTCHA traffic charts by type and country |
| [Audit](/en/portal/audit/) | Search individual CAPTCHA records |
| [Access Control](/en/portal/access-control/) | Rules that allow, block or challenge requests |
| [Settings](/en/portal/settings/) | Per-site CAPTCHA settings |
| [Site Management](/en/portal/sites/) | Create sites and copy their keys |
| [User Management](/en/portal/users/) | Invite team members and set their roles |
| [API Keys](/en/portal/api-keys/) | Keys for programmatic access |
| [Protect](/en/portal/protect/) | Edge protection instances and their settings |
| [Get Started](/en/portal/get-started/) | Step-by-step integration guide |

When Protect is enabled, a Protect group adds [Overview, Challenge Outcomes, Traffic Trends](/en/portal/protect-traffic/), [Verdicts](/en/portal/verdicts/) and [Agent Trust](/en/portal/agents/).

Pages that act on one site use the site selector at the top. Select a site first, or the page shows **No Site Selected**.

The menu also links to these docs, Discord, a support call booking, GitHub and the status page.
