**Settings** configures the selected site. Save with the button at the bottom; **Apply to Multiple Site Keys** copies the settings to other sites.

| Section | What it controls | Read more |
|---|---|---|
| CAPTCHA type | Frictionless (recommended), Proof of Work, Image, Puzzle or Icon Order | [CAPTCHA types](/en/basics/captcha-types/) |
| Access & Scope | Where the CAPTCHA may run, such as allowed domains and WebView blocking | |
| Detection | Frictionless thresholds, honeypot and auto-ban | [Honeypot](/en/advanced/honeypot/) |
| Challenge | Difficulty for Proof of Work, image, puzzle and icon order challenges, plus the audio alternative | [Image threshold](/en/advanced/image-threshold/) |
| Verify | Timeouts and whether to store verify metadata | [CAPTCHA timeouts](/en/advanced/captcha-timeouts/) |
| IP Validation | Rules for IP changes between challenge and verify | [IP validation rules](/en/advanced/ip-validation-rules/) |
| Traffic Filter | Block VPN, proxy, Tor, datacenter, crawler and other traffic | [Traffic filter](/en/advanced/traffic-filter/) |
| Email Filter | Email pattern rules and spam domain checks | [Spam filter](/en/advanced/spam-filter/) |

Traffic and email filtering are paid features.
