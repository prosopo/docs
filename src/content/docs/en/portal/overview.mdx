**Overview** is the first page you see after signing in. It shows:

- **Active Sites**, with a link to [Site Management](/en/portal/sites/).
- **Current Tier**, with **Upgrade Plan** or **Manage Subscription**. See [Account and billing](/en/portal/account-and-billing/).
- **Live Sessions**: recent CAPTCHA sessions for the selected site. If none have arrived yet, follow **Set up the widget**.
- **Quick Links**: the selected site's **Site Key** and **Secret Key**, plus shortcuts to Traffic, Site Management, Settings, API Keys, Get Started and these docs.

## Top IPs

**Overview → Top IPs** lists the IP addresses with the most sessions. Choose a **Window** (from the last 5 minutes to the last 30 days) and how many **Rows** to show.
