title: Audit
description: Search individual CAPTCHA records.
i18nReady: true
---

**Audit** lets you search and review individual CAPTCHA records for the selected site.

**Search Criteria** filter by request fingerprint (IP address, JA4 fingerprint, user agent), user account, domain, VPN status, WebView, framing, geolocation, device type, session type (Proof of Work, Image, Puzzle, Icon Order, Audio), blocked, outcome, status and a time range. **Clear all** resets them.

**Search Results** can be filtered further, and **Columns** chooses which fields to show. Selected rows can be given a **Label**.

See [Audit](/en/advanced/audit/) for details on each field.
