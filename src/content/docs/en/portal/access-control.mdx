title: Access Control
description: Rules that allow, block or challenge requests.
i18nReady: true
---

**Access Control** manages security rules for the selected site. It has two kinds of rule:

- **Procaptcha Rules** apply to CAPTCHA requests. Click **Create Procaptcha Rule**.
- **Protect Rules** apply to traffic through [Prosopo Protect](/en/portal/protect/). Click **Create Protect Rule**.

Rule types include **Geo Blocking**, **OS Restriction**, **Browser Restriction** and **Header Restriction**. Users with the Viewer role see **Permission denied** when they try to change rules.

See [Access control rules](/en/advanced/access-control-rules/) and [Geo-blocking](/en/advanced/geo-blocking/).
